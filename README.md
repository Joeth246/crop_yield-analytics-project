# crop_yield-analytics-project
Excel-based crop yield analytics dashboard project with Pivot Tables, KPI analysis, and interactive visualizations.

## Project Overview
This project analyzes agricultural crop yield data using Microsoft Excel.

The goal of the project was to:
- clean and organize large datasets
- perform statistical analysis
- create Pivot Tables
- build interactive dashboards
- identify trends affecting crop yield

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- Statistical Functions

## Key Analysis Performed
- Average yield by crop type
- Yield comparison by region
- Irrigation impact on yield
- Fertilizer impact on yield

## Dashboard Features
- Interactive slicers
- KPI summaries
- Visual trend analysis
- Dynamic Pivot Charts

- Data Cleaning
